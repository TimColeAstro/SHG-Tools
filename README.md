I use these scripts to help me use my MLAstro SHG-700 spectroheliograph (SHG) efficiently. They are written for SharpCap Pro image capture software
(https://www.sharpcap.co.uk), and won't be directly useable for any other imaging software.
The icons I've provided for SharpCap custom buttons are my own original work. You may use them for any non-commercial project.
These scripts are based on SHG-700/SharpCap scripts written by Christian Bennich and Patrick Hsieh, and I thank them for making
their work available for other SHG users.
While I find these scripts useful, perhaps you won't. In any case, I'm posting them here for your edification or amusement.

Attribution and background information are included in the source files.
